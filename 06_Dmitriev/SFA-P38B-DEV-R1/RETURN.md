# Формат повернення

Збережіть root папку і source paths. Додайте реалізацію, candidate_tests, CHANGELOG, patch, TRACEABILITY case→file→result, SHA256 до/після, Python/platform, точні команди й raw stdout/stderr/exit codes. Відділіть PASS/FAIL/NOT_RUN, вкажіть усі limitations та integration proposal. Не оголошуйте live system готовою. Не змінюйте protected files, призначення або контракт.

Цей RETURN.md є read-only інструкцією. Власний звіт збережіть у raw_logs/RETURN_REPORT.md; не редагуйте цю інструкцію або інші protected files.
