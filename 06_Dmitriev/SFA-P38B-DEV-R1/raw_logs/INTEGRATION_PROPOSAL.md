# Предложение подключения

Этот файл — предложение для следующего интегратора. Сам пакет ничего в общий runtime не встраивает.

## Куда подключать

Готовый вызов:

`make_catalog_config_resolver(service, *, client_id, catalog_version, clock)`

Возвращённую функцию передают существующим аргументом, без новой обёртки:

`resolve_campaign_projection(campaign, resolve_config=resolver, now=explicit_now)`

`service` — уже принятый `CatalogService`. Адаптер сам сервис, права и approval не создаёт.

## Одна доверенная точка времени

Часы resolver и `now` для F128 должны быть одной и той же доверенной точкой времени.
Её задаёт host. Адаптер не записывает `service._ports.now` и не вызывает системные часы.
Поэтому сборка host должна сама выставить время порта каталога и передать тот же момент
в `clock` и в `now=` проекции.

## Версия

Версия каталога закреплена в экземпляре resolver. Для другой версии host создаёт новый
resolver. Старый экземпляр продолжает читать свой pin. Автоматического выбора current version нет.

## Что сделать интегратору перед merge

1. Заново сверить hash защищённых зависимостей с текущим HEAD.
2. Убедиться, что другой writer не занял путь `source/first_materials_integration/catalog_config.py`.
3. Сделать backup только разрешённого пути.
4. Добавить этот один файл. Общий `__init__.py` не создавать.
5. Повторить baseline и компонентные проверки уже на установленных байтах.
6. Откат — удаление только этого принятого файла по его hash. Чужие изменения не удалять.

## Что этим подключением не становится готовым

Нет SQL, реальной отправки, production-установки, credentials и правки системной конфигурации.
`release_mode` остаётся `NO_OUTBOUND`: чтение каталога не даёт права отправлять.
F1-29, мост F1-22, P08 materials.save/dispatch и транспорт P43 здесь не реализованы.
Исторические B8 CP2/CP3/CP4 в этот адаптер не входят и не считаются выполненными.
Installed/connected приёмка остаётся отдельным шагом после независимого review.
